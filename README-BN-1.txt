UL TOP UP BD — ওয়েবসাইট টেমপ্লেট

চালানোর নিয়ম:
1. ZIP ফাইল Extract করুন।
2. index.html ফাইল ব্রাউজারে খুললে ওয়েবসাইট দেখা যাবে।
3. অনলাইনে প্রকাশ করতে পুরো ul_topup_site ফোল্ডারটি Netlify, Render Static Site বা অন্য static hosting-এ আপলোড করুন।

WhatsApp অর্ডার চালু করতে:
1. script.js ফাইল খুলুন।
2. const SUPPORT_WHATSAPP = ''; লাইনে আপনার WhatsApp নম্বর আন্তর্জাতিক ফরম্যাটে শুধু সংখ্যা দিয়ে লিখুন।
   বাংলাদেশ উদাহরণ: 8801XXXXXXXXX (এটি নমুনা; নিজের নম্বর বসাবেন)।
3. ফাইল সেভ করে আবার আপলোড করুন।

গুরুত্বপূর্ণ:
- এটি একটি front-end template; অর্ডার ডেটাবেস, লগইন, অটো পেমেন্ট বা অ্যাডমিন প্যানেল যুক্ত নেই।
- প্যাকেজের দাম ইচ্ছাকৃতভাবে যোগ করা হয়নি, কারণ সঠিক দাম দেওয়া হয়নি।
- আসল পেমেন্ট নেওয়ার আগে পেমেন্ট নির্দেশনা, মূল্য এবং অর্ডার যাচাই প্রক্রিয়া নিজে নিশ্চিত করুন।
- আপনার সাইটের ডোমেইন/হোস্টিং এবং WhatsApp নম্বর আলাদাভাবে সেট করতে হবে।
